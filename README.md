## 🧪 Testing Is Part of the Build

> Tests and release pipelines are part of the architecture, not a checkbox at the end of a sprint.

| Layer | Tools | What it protects |
|:--|:--|:--|
| Unit / integration | Jest | Logic and service contracts, safe refactors |
| End-to-end | Cypress · Playwright | Critical user journeys across browsers |
| Performance | k6 · JMeter | Throughput and latency under load |
| API | Postman automation | Contract and regression checks in CI |
| Release | GitHub Actions · Docker | Repeatable, zero-downtime deploys |
